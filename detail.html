Workshop Keterampilan Digital

Workshop Web Design

Pelajari HTML dan CSS untuk membangun website yang responsif, terstruktur, dan berestetika modern.

Deskripsi Kegiatan

Workshop Web Design ini dirancang khusus bagi mahasiswa yang ingin memahami pondasi pembuatan website dari nol. Melalui sesi interaktif dan praktik langsung di lab komputer, peserta akan mempelajari struktur dokumen menggunakan HTML5 semantic dan tata letak modern menggunakan CSS3 (Box Model, Flexbox, dan Media Queries).

Tidak diperlukan pengalaman coding mendalam sebelumnya. Seluruh mahasiswa dari berbagai fakultas dan jurusan dipersilakan bergabung untuk memperkaya portofolio digital mereka.

Materi yang Dipelajari

  • Pondasi Dokumen: Sintaks HTML, Tag Semantik, dan Struktur Halaman.
  • Prinsip CSS: Cascading, Specificity, dan Inheritance.
  • CSS Box Model: Margin, Border, Padding, dan Content.
  • Typography & Color Harmony: Pemilihan font dan palet warna kontras tinggi.
  • Komponen Reusable: Membuat kartu (card), tombol (button), dan formulir responsif.
  • Publishing & Testing: Tips hosting sederhana dan pengujian tampilan di smartphone.
